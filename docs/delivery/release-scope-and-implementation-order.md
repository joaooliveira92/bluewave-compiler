# DESIGN-55: Release Scope And Implementation Order

> **Canonical status:** Normative migration of `SOURCE-DESIGN-v1.0.md` v1.0.
> **Requirement language:** Existing source wording is preserved. Where the source uses mandatory language, it is normative. Ambiguities are tracked in `docs/OPEN-ISSUES.md`; implementations MUST NOT invent unresolved behavior.
> **Stable document ID:** `DESIGN-55`

Milestone 1 — Strategic Campaign Kernel:

- Campaign compiler.
- Nations and world.
- Economy.
- Research.
- Ship design and construction.
- Deployment.
- Diplomacy.
- War and peace.
- Monthly phase pipeline.
- Save/load and hashes.
- Deterministic auto-resolution.

Milestone 2 — Surface Tactical Core:

- Movement.
- Spotting.
- Divisions.
- Gunnery.
- Basic armor and damage.
- Weather.
- Battle results.

Milestone 3 — Advanced Surface Warfare:

- Torpedoes.
- Mines.
- Submarines.
- Coastal defenses.
- Smoke.
- Detailed damage control.

Milestone 4 — Aviation:

- Aircraft development.
- Squadrons.
- Airbases.
- Carriers.
- CAP.
- Strikes.
- AA.

Milestone 5 — Electronics and Missile Era:

- Radar.
- Fighter direction.
- Data links.
- Electronic warfare.
- Guided weapons.
- SAM.
- CIWS.
- Jets and helicopters.

Milestone Rule:

- Later-era content may exist in the canonical pack before its tactical system is
  complete, but no scenario is declared fully supported until all required
  systems for its expected era pass acceptance.
