# Event Definition And Effects

> Extracted contract view. The originating `DESIGN-*` document remains normative.

Event Definition:

- Stable identifier.
- Version.
- Scope.
- Eligibility.
- Trigger phase.
- Weight or schedule.
- Mutual-exclusion group.
- Cooldown.
- Visibility.
- Choices.
- AI-choice policy.
- Effects.
- Follow-ups.
- Expiration.
- Historical-mode restrictions.
- RNG stream.
