# DESIGN-40: Torpedoes

> **Canonical status:** Normative migration of `SOURCE-DESIGN-v1.0.md` v1.0.
> **Requirement language:** Existing source wording is preserved. Where the source uses mandatory language, it is normative. Ambiguities are tracked in `docs/OPEN-ISSUES.md`; implementations MUST NOT invent unresolved behavior.
> **Stable document ID:** `DESIGN-40`

Torpedo State:

- National torpedo model.
- Platform compatibility.
- Mount position.
- Tube count.
- Ammunition.
- Damage state.
- Fire solution.

Use:

- Normally automated by tactical AI.
- Captain mode permits manual launch.
- Underwater tubes cannot fire above 25 knots.

Solution Quality:

- Target range.
- Relative bearing.
- Target speed and course.
- Platform maneuver.
- Crew and training.
- Sea state.
- Technology.
- Visibility and identification.

Technology:

- New torpedoes require production and supply where the ruleset models inventory.
- Old ships adopt new weapons only if compatible and supplied.
- Increased torpedo weight can require refit for incompatible mounts.

Oxygen Torpedoes:

- Improve performance.
- Increase tube-hit explosion risk.

Damage:

- Major flotation damage.
- Progressive flooding.
- Machinery damage.
- Turret or system loss.
- Underwater-tube hits can cause severe flooding.
