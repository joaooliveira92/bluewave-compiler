# Implementation reports

Historical, append-only records: one file per sprint / increment / acceptance gate,
written by the implementator and reviewer roles. They are evidence of what was done
and validated at that time — **not** a live status board.

- Live status: [`docs/PROGRESS.md`](../../docs/PROGRESS.md).
- Live backlog / next action: [`../SPRINT-PLAN.md`](../SPRINT-PLAN.md).
- Naming: `<sprint-slug>[-<increment>](-<topic>).md`, oldest first by insert order.
- Do not edit a report after it is written; supersede it with a new report.
- Reports are reference material for an agent; prefer PROGRESS.md for current state.
