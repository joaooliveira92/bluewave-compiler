Opening month **1880-01**. The 1880 scenario ruleset (`balance.yaml` → `ship.classification`,
`rulesetVersion: 2`, ADR-0116) admits slow, belted, heavy-gun coast-defence/casemate ironclads as
capital (B): displ ≥ 1,500,000 kg, BELT_MAIN ≥ 101,600 µm (4 in), speed < 18 kn, main gun > 152,400 µm,
1–2 main-gun mounts (`classFacts.mainTurretCount` = number of compiled `MAIN_GUN` placements).

A `MAIN_GUN` placement is one component of category `MAIN_GUN`; a casemate/broadside battery is modelled
by consolidating guns into 1–2 side mounts (`barrels` doubles as "guns grouped in one battery mount",

## Decisions

1. **Spain 254 mm** — `gun_rml_10in_12ton_300pdr`, a DISTINCT family (research note
   `ship-building-1880-coast-defence-followups.md` §1: the Armstrong 10-inch **12-ton** 300-pdr firing
   ~136 kg, gun ~12.2 t — not the Woolwich 10-inch 18-ton firing 181 kg/18.3 t). The profile overlay
   `es_armstrong_254` is re-pointed at it; no shell-mass override on the 18-ton family.
2. **Portugal** — the 263 mm is an EXACT match to `gun_bl_263mm_rkl20`; its Portuguese use is CASEMATE
   (add CASEMATE to the overlay and a CASEMATE mount). *Vasco da Gama* was **foreign-built** (Thames
   Iron Wks, London), so it exceeds Portugal's domestic industrial ceiling (`maxPracticalDisplacementKg`
   1,400,000 = largest domestic hull, *Duque da Terceira* 1,406 t) and the B floor (1,500,000). The
   ceiling is NOT raised (no capability inflation); the industrial-ceiling test exempts a documented
   foreign-built reconstruction.
3. **F3 ceilings** — no period source gives a separate *domestic* heavy-gun figure for any of the seven
   `heavyGunProduction: IMPORTED` nations (research §2), so `maxImportedGunCaliberUm` stays absent for
   all; recorded deferred.
4. **New family values** — bore/designation/mount from navypedia (SINGLE-SOURCE → `DERIVED`); gun masses
   where sourced (Krupp Von Müller 1879; Whitworth Conway's) → `DERIVED`; every shell/charge/MV not in a
   print source stays `ESTIMATE`. German `gun_bl_263mm_rkl20` is NOT edited (preserve germany content;
   the Von Müller correction is recorded deferred).

## Anti-substitution fixes folded in

The profile overlays currently map new guns onto numerically-close existing families; each is
re-pointed at its own family: netherlands `nl_krupp_283` (263→283), portugal `pt_krupp_149`
(152→149), brazil `br_whitworth_229` (254→229), japan `jp_krupp_235mm` (254→235) and `jp_krupp_173mm`
(203→173), austria `ah_krupp_209` (203→209), spain `es_armstrong_254` (18-ton→12-ton).
