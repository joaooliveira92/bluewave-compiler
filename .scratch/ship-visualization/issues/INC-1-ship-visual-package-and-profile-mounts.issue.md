# INC-1: ship-visual package, catalog pipeline, and gun mounts in the profile

**Type:** implementation
**Status:** resolved
**Blocked by:** none
**Frontier:** no

Spec: [spec.md](../spec.md) SV-R1..R8, SV-R12; ADR-0148.

## What to build

The tracer slice, end to end:

- the new pure package with its vocabulary, resolver and placement;
- the schema, the YAML holding the complete `X × DREADNOUGHT` set, the generator and the
  sync test;
- the renderer adapter from the compiled design, and the profile mount layer;
- the boundary test, and the package added to the runtime-free gate.

## Acceptance criteria

- [x] AC-1, AC-2 tests pass in `@bluewave/ship-visual`.
- [x] The profile draws every gun placement of the reference design with `data-part`.
- [x] The boundary test passes, and `assert-runtime-free` covers `packages/ship-visual/src`.

## Answer

- `@bluewave/ship-visual` holds the vocabulary (`visualEraOf`, `nationStyleOf`, `sizeBandOf`, `mountClassOf`), the
  resolver (`resolveMount` / `resolveMast`, 4-step chain) and pure placement (`placeMounts`).
- The catalog source is `content/ship-visual/parts.yaml`, holding the complete `X × DREADNOUGHT` set (15 entries).
  It is decoded by `ShipVisualCatalogSchema` and generated by `catalog:generate`. `catalog-sync.test.ts` pins the
  YAML to the generated module, checks unique ids and keys, and checks the default's coverage.
- The renderer reads the compile through `visualMountInputs` / `visualLook` (via `planModel`), and
  `ProfileMountLayer` draws in front of the superstructure.
- `boundary.test.ts` enforces SV-R12. The package is in the runtime-free gate, and turbo's test inputs cover the YAML.
- Reaction from the snap (ironclad starter): casemates are seated at the deck edge and their drawings hang below it,
  replacing the mid-freeboard seat.
- Validation:
  - `@bluewave/ship-visual` tests: 71/71.
  - hull-plan tests: 203/203.
  - `tsc` is clean for the touched files.
  - `pnpm format` and `pnpm lint` are clean.
  - `assert-runtime-free` passes with 16 roots.
  - `pnpm snap` of the Drawing Board (torpedo gunboat, then Alexandra) had a clean console, and the renderer bundle
    contains no yaml/effect.
