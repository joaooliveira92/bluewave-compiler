# INC-3: masts in the profile

**Type:** implementation
**Status:** open
**Blocked by:** INC-1
**Frontier:** yes

Spec: SV-R8, SV-R9, SV-R11.

## What to build

Authored mast symbols (universal V/P/D), conventional placement from the superstructure
zone, height clamp, the mast layer behind the hull, and a `convention` legend chip.

## Acceptance criteria

- [ ] A design with a superstructure zone shows a foremast and a mainmast, and one without
      shows none.
- [ ] Masts never draw above the drawing's top pad.
- [ ] The legend explains masts as a convention.
