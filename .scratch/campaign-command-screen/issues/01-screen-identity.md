# Screen identity and layout regions

**Type:** grilling
**Status:** resolved
**Blocked by:** none

## Question
Is the command screen a replacement of the Overview as campaign home, and what are its regions? Decide: (a) one screen vs Overview + drawers, (b) how the RTW3 regions (tab strip, area tree, map, nation panel, budget panel, action grid, nation strip, Turn) map onto the existing header, BottomNav and Overview cards, (c) whether the map goes full-bleed (closing parity ticket 03's remaining half), (d) what happens to the header's Advance Month vs RTW3's Turn button, (e) which Overview content (month report, priorities) survives and where.

## Answer

Owner accepted all six recommendations (2026-10-08):

1. **Home:** the command screen replaces the Overview as campaign home. Month report and priorities become collapsible panels around the map.
2. **Map:** full-bleed centre canvas (closes parity ticket 03's remaining half, M-1); panels overlay at the edges, no map-in-a-card.
3. **Status/budget:** one collapsible strip above the BottomNav with two groups (nation, budget). Real values only; each deferred readout shows "Not yet modelled" with a reason; monthly budget labelled "projected".
4. **Turn:** the header's Advance Month stays the single Turn control, keeping the pre-turn review dialog. No duplicate button.
5. **Right rail:** slim right-edge nation rail with relation/war status from Diplomacy; intel bars deferred (ticket 07 settles details).
6. **Tabs and action grid:** not copied as such; tickets 05 and 06 map them onto BottomNav, map lenses and drawers, with no second navigation surface.
